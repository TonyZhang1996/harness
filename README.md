# AI Harness

AI Harness 是一个面向软件工程的通用大模型编排与 Agent 执行框架。

它的目标不是服务于某一个模型，而是建立一层统一、开放、可扩展的 Harness，让不同厂商、不同架构、不同能力的大模型能够在同一套任务、上下文、工具和工作区协议下协同工作。

通过模型适配、智能路由、上下文管理、工具调用、执行控制和结果验证，AI Harness 将模型能力转化为可组合、可调度、可验证、可持续演进的工程能力。

最终，AI Harness 将成为一个能够接入和调度各种大模型、理解复杂开发任务、操作真实项目工作区，并完成完整软件工程流程的通用 AI 开发基础设施。

## 当前能力

Agent 可以通过工具在指定工作区内：

- 读取 UTF-8 文件
- 创建新文件
- 创建或覆盖写入文件
- 删除单个文件

所有文件路径都会限制在工作区内；文件修改不会经过符号链接路径，删除工具不会删除目录。

命令行默认把当前目录作为工作区，也可以显式指定：

```bash
ai-harness --workspace ./demo "创建一个 README.md 并运行项目检查"
```

当前版本只提供文件级操作。执行任意 shell 命令、运行测试和自动应用复杂补丁，应该在后续加入独立的权限和确认策略后再开放。
